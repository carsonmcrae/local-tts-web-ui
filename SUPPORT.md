# Getting help

| You want to…                      | Go to                                                                                                                                                                   |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Learn how to use Local TTS        | The [wiki](https://github.com/carsonmcrae/local-tts-web-ui/wiki), starting with [Getting Started](https://github.com/carsonmcrae/local-tts-web-ui/wiki/Getting-Started) |
| Fix a setup or playback problem   | [Troubleshooting](docs/guides/troubleshooting.md); run `npm run doctor` and include its output when you ask for help                                                    |
| Ask a question or share an idea   | [Discussions](https://github.com/carsonmcrae/local-tts-web-ui/discussions)                                                                                              |
| Report a bug or request a feature | [Issues](https://github.com/carsonmcrae/local-tts-web-ui/issues/new/choose); the forms ask for what's needed to reproduce it                                            |
| Report a security vulnerability   | [Private vulnerability reporting](https://github.com/carsonmcrae/local-tts-web-ui/security/advisories/new), never a public issue ([SECURITY.md](SECURITY.md))           |
| Contribute code or documentation  | [CONTRIBUTING.md](CONTRIBUTING.md)                                                                                                                                      |

This is a volunteer project, so replies may take a few days. Please don't paste document text, voice
recordings or other personal data into public issues.
