# Background music: credits and licences

TTSNative's background music is a small library of recordings that their creators placed in the
public domain (CC0 1.0, or a public-domain release). Anyone may copy, change, share and sell them,
also inside other work, without asking and without giving credit. We credit every creator anyway.

That covers shipping them in TTSNative's public source repository, in its installers and in
audio people make with it, with or without changes. Each file contains only the audio: no cover
art, titles or other tags from the originals.

Each file here is an edited excerpt: trimmed, blended at the end so it loops without a seam, matched
in loudness to sit below the narration, and encoded as Opus in WebM. How each was made, and the
SHA-256 of the original download, is recorded in `apps/web/src/features/music/library.json` in the
source repository, and `npm run music:build` rebuilds the files from the originals.

Licences were checked on each source page on the date shown. If you believe a track is listed
wrongly, please open an issue at https://github.com/carsonmcrae/ttsnative/issues.
