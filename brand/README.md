# TTSNative brand

TTSNative is natural text-to-speech that runs natively, on your own device. "Native" means local, on-device
processing. The identity is about speech, text and local computation, and nothing else: it doesn't use
cultural or Indigenous imagery of any kind.

Every file here is generated by [`scripts/brand/build-brand.mjs`](../scripts/brand/build-brand.mjs) from
one definition of the symbol, colours and type. Change the script, not the exported files, and run
`node scripts/brand/build-brand.mjs` to regenerate them (Chromium from Playwright and FFmpeg are needed).

## The symbol

An **N drawn as five waveform bars**. The outer bars are the stems of the N; the three shorter bars step
down from top left to bottom right to form its diagonal. It reads as a letter, as a sound wave and as a
level meter, and at 16 pixels the bars resolve into a clean N.

| Use                               | File (`svg/`)                                                         |
| --------------------------------- | --------------------------------------------------------------------- |
| App icon, favicon, avatars        | `ttsnative-app-icon.svg` (white bars on the gradient tile)            |
| Symbol on light backgrounds       | `ttsnative-symbol.svg`                                                |
| Symbol on dark backgrounds        | `ttsnative-symbol-dark.svg`                                           |
| One-colour (print, embossing)     | `ttsnative-symbol-ink.svg`, `ttsnative-symbol-white.svg`              |
| Horizontal logo (headers, README) | `ttsnative-logo-horizontal.svg`, `ttsnative-logo-horizontal-dark.svg` |
| Stacked logo (square spaces)      | `ttsnative-logo-stacked.svg`, `ttsnative-logo-stacked-dark.svg`       |
| README banner                     | `ttsnative-banner.svg`, `ttsnative-banner-dark.svg` (1280 × 400)      |
| Social preview                    | `ttsnative-social-preview.svg` (1280 × 640)                           |

`png/` has exports at the sizes in each file name, and `webp/` has smaller copies of the large images.
The app and the website serve `favicon.svg`, `apple-touch-icon.png`, `icon-192.png` and `icon-512.png`,
copied by the script. The wordmark SVGs embed the Inter font, so they render the same everywhere.

## Colour

| Name        | Hex       | Use                                                                 |
| ----------- | --------- | ------------------------------------------------------------------- |
| Indigo      | `#4F46E5` | Primary. Gradient start, "Native" in the wordmark, the app's accent |
| Signal cyan | `#0891B2` | Gradient end                                                        |
| Ink         | `#14151A` | "TTS" in the wordmark, text on light backgrounds                    |
| Paper       | `#F7F6F3` | Light backgrounds (the app's light theme)                           |
| Night       | `#0E0F14` | Dark backgrounds                                                    |
| Indigo 200  | `#A5B4FC` | "Native" and the gradient start on dark backgrounds                 |
| Cyan 300    | `#67E8F9` | Gradient end on dark backgrounds                                    |

The gradient always runs diagonally, from top left (indigo) to bottom right (cyan). In the app, UI colours
come from the accessible tokens in `apps/web/src/styles/index.css`, which use the same indigo.

## Type

The wordmark is **Inter Bold** with tight tracking (−0.02 em). "TTS" is set in the text colour and
"Native" in indigo, which shows both halves of the name. Headings in the app and on the website use
Inter, and the reader uses Literata for long text. Both are licensed under the SIL Open Font License.

## Spacing and size

- **Clear space:** keep at least the width of two bars (about a quarter of the symbol's height) clear on
  every side.
- **Minimum size:** the symbol at 16 px (use the app icon at 16–32 px); the horizontal logo at 120 px
  wide.
- In a horizontal lockup the gap between the symbol and the name is one bar's height in the diagonal
  (about a third of the symbol).

## Please don't

- stretch, rotate, outline or add shadows or effects to the symbol or the name;
- recolour it outside this palette, or put the light variant on dark backgrounds (use the `-dark`
  files);
- rebuild the wordmark in another typeface or split "TTSNative" into two words;
- pair the brand with imagery unrelated to speech, text or computing.

The TTSNative name and logo identify this project. See [ATTRIBUTION.md](../ATTRIBUTION.md) for how to
