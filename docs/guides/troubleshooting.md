# Troubleshooting

Start with `npm run doctor`. It checks Node, uv, the Python environment, installed models, GPUs, ports and
disk space without changing anything. For the Windows app, see [below](#windows-app).

| Symptom                                                                                                                           | Cause and fix                                                                                                                                                                                                                                                                              |
| --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Node.js 22.22 or newer is required`                                                                                              | Install the current Node LTS (see `.nvmrc`).                                                                                                                                                                                                                                               |
| `Installing the locked Python dependencies failed` on first run                                                                   | uv needs internet access to download Python 3.12 and packages. Check proxies/firewalls for `github.com`, `pypi.org` and `files.pythonhosted.org`, then rerun `npm run dev`.                                                                                                                |
| `Refusing download from unapproved host` / `Checksum mismatch` (setup), or "unapproved location" / "failed its checksum" (models) | A proxy or mirror changed a download. Nothing was installed; don't bypass the check. Retry on a normal connection.                                                                                                                                                                         |
| "Install the voice model to start listening"                                                                                      | The Kokoro model isn't installed (offline first run or `LTTS_SKIP_MODEL_DOWNLOAD=1`). Click **Install Kokoro** in the banner or in Settings → Engines & models, or run `npm run setup`.                                                                                                    |
| A PDF says "no text layer … scanned images"                                                                                       | The PDF contains pictures of text. OCR isn't supported yet; export the text from the original or run OCR first.                                                                                                                                                                            |
| "contents don't match its extension"                                                                                              | The file was renamed (e.g. a `.txt` named `.pdf`). Use the real format.                                                                                                                                                                                                                    |
| Playback never starts in the browser                                                                                              | Check Settings → Engines & models. If audio is generated but silent, check the system output device; the app plays standard WAV.                                                                                                                                                           |
| Recording says it needs a secure page                                                                                             | Browsers only allow microphones on `localhost`/HTTPS. Record on the computer running the app, or import a recording.                                                                                                                                                                       |
| Chatterbox install fails                                                                                                          | It downloads several gigabytes (PyTorch and the model; Settings shows the size for each option). Check free disk space and connection, then retry; partial downloads resume. The terminal shows uv's error.                                                                                |
| Chatterbox shows **Update available**                                                                                             | The app's locked cloning packages changed since you installed (for example a security fix), or the install predates lock tracking. Click **Update Chatterbox Turbo** in Settings → Engines & models or the Voice Studio. Only changed packages download; cloning pauses until it finishes. |
| Chatterbox update fails                                                                                                           | Nothing is removed: the current install keeps working and the update stays on offer. Check your connection and free disk space, read uv's error in the terminal, then retry.                                                                                                               |
| Chatterbox is very slow                                                                                                           | Without an NVIDIA GPU (or Apple Silicon) cloning runs on CPU, which is slower than real time.                                                                                                                                                                                              |
| `Port … is in use`                                                                                                                | The app picks the next free port automatically; or set `LTTS_API_PORT` / `LTTS_WEB_PORT`.                                                                                                                                                                                                  |
| Windows: `failed to remove file … ltts.exe` while syncing                                                                         | The dev server is still running and holds the file; stop it (Ctrl+C) and rerun.                                                                                                                                                                                                            |
| Start over                                                                                                                        | Stop the app and delete `data/` (your library, recordings and models) and `.tools/` (uv and Python).                                                                                                                                                                                       |

## Windows app

The app's logs are in `%LOCALAPPDATA%\com.ttsnative.desktop\logs` (**Settings → About → Open log
folder**, also offered by the start-up screen when the server can't start): `server.log` is the bundled
server's output for this run, `server.previous.log` the run before, and `desktop.log` the shell's own
notes (the port it chose, start failures). None of them contains document text. Design:
[desktop-and-releases.md](../architecture/desktop-and-releases.md).

| Symptom                                            | Cause and fix                                                                                                                                                                                                                                                               |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SmartScreen: "Windows protected your PC"           | The installer has no Authenticode signature yet. **More info → Run anyway**, after checking the file against the release's `SHA256SUMS.txt` (or `gh attestation verify <file> --repo carsonmcrae/ttsnative`). Updates are verified separately, by their minisign signature. |
| Smart App Control or antivirus blocks a file       | Same cause. Allow TTSNative, or run from source.                                                                                                                                                                                                                            |
| "Some of TTSNative's files are missing"            | `runtime\python\ttsnative-backend.exe` (or more) is gone from `%LOCALAPPDATA%\TTSNative`, for example removed by antivirus. Reinstall; the data folder is separate and kept.                                                                                                |
| "…took too long to start"                          | The server didn't answer `/api/health` within 180 s, which can happen on the first start while Windows scans the new files. **Try again**; if it persists, read the end of `server.log`.                                                                                    |
| "…stopped while starting" / "…couldn't be started" | The server exited or couldn't be launched; the start-up screen's **Technical details** show the end of `server.log`.                                                                                                                                                        |
| "No free local port was found"                     | Every port from 8770 to 8789 on `127.0.0.1` is taken. Find the owner with `netstat -ano \| findstr 127.0.0.1:87`, close it, and **Try again**.                                                                                                                              |
| Settings for the theme and reading text reset      | 8770 was busy, so the app used the next free port; per-device settings live in the page's `localStorage`, which is per origin (port). They return when the app gets 8770 again.                                                                                             |
| `LTTS_*` variables have no effect                  | Deliberate: the app removes every inherited `LTTS_*` variable before starting its server and sets its own. Configure a source install instead.                                                                                                                              |
| "TTSNative needs about … MB free on drive …"       | The installer's pre-install hook (`apps/desktop/windows/hooks.nsh`) found less free space than Tauri's size estimate plus 200 MB and aborted before writing anything (exit code 3); in `/UPDATE` mode it reopens the installed version. Free space and retry.               |
| "No update is available right now"                 | The updater got no release manifest (`latest.json` not found, as before the first release that ships one). It is noted in `desktop.log` and not remembered as a check; it isn't a connection failure.                                                                       |
| An update fails                                    | Download, signature and launch failures change nothing. If the installer itself fails part-way, reinstall from ttsnative.com; data is kept.                                                                                                                                 |
