The first version, shared as Local TTS: a simple page in your web browser that turned text files,
PDFs and EPUB books into natural-sounding speech on your own computer with the Kokoro voice model.
It had to be set up by hand with developer tools. It was recorded as release 1.0.0 on October 19,
2026, is no longer maintained, and was replaced by TTSNative 2.0.0.

## New

- Turn a text file, PDF or EPUB book into a spoken audio file (WAV) on your own computer.
- Choose from more than 50 voices and set the speaking speed.
- Preview a voice on a sample sentence before using it; previews you've heard before play instantly.
- Convert every text file in a folder in one go.
- The voice model downloads by itself the first time you start the app.
