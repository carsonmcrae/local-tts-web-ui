# GitHub Release descriptions for earlier versions

Prepared for the maintainer's approval; nothing here has been published. Each file puts the
plain-language notes from `docs/releases/` first and keeps the original description, unchanged, in a
folded "Original release notes" section, so no history is lost. To apply them, see
[release-process.md](../../guides/release-process.md#historical-releases). Releases made with the release
workflow get their description from `docs/releases/X.Y.Z.md` automatically.
