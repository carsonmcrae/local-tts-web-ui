# Sound effects: open-source candidates

Facts gathered on 2026-10-21 from the GitHub REST API, the npm registry, PyPI and Hugging Face
model cards. Nothing was cloned, installed or executed; licence texts were read from the
repositories' LICENSE files, model-card front matter and the sites' own terms pages. "Open issues"
is GitHub's count, which includes pull requests. What the findings mean for the design is in
[sound-effects.md](sound-effects.md).
