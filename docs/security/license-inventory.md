# License inventory

> **In short:** the project is MIT. Runtime dependencies are permissive (MIT, BSD, Apache-2.0, PSF,
> ISC) with two reviewed exceptions used for Kokoro's phonemisation: `phonemizer` and the espeak-ng
> library bundled by `espeakng-loader`, both GPL-3.0. Model weights are Apache-2.0 (Kokoro) and MIT
> (Chatterbox).

The full, generated list of runtime packages and licences is in
[license-inventory.generated.md](license-inventory.generated.md). The production web build (and the
`web-ui` archive attached to each release) includes `THIRD-PARTY-LICENSES.md`, written by Vite, with the
licence text of every package and font it bundles. Regenerate it with
`npm run licenses`; the command fails if a dependency has an unknown licence or an unreviewed
GPL/AGPL/LGPL licence.

## Reviewed exceptions

| Component                                              | Licence          | Why it is acceptable here                                                                                                           |
| ------------------------------------------------------ | ---------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| phonemizer (via kokoro-onnx)                           | GPL-3.0-or-later | Source installs: installed from PyPI by uv. The Windows installer redistributes it unmodified, with its licence and a source offer. |
| espeak-ng (bundled in espeakng-loader wheels)          | GPL-3.0          | Same as above; the release attaches its exact source and build scripts.                                                             |
| libsndfile, mpg123, LAME (bundled in soundfile wheels) | LGPL-2.1         | Dynamically loaded, unmodified, and replaceable in the Windows install folder; licence and source offer as above.                   |
| certifi (CA bundle, via httpx)                         | MPL-2.0          | File-level copyleft that applies only to modified files; shipped unmodified, with its licence, in the Windows installer.            |

**The Windows installer is a bundled build** and meets these obligations: every installer carries
`THIRD-PARTY-NOTICES.txt` (generated by `scripts/desktop/notices.mjs`: every Python package, every Rust
crate in `TTSNative.exe`, CPython's libraries, uv, the model) and a `licenses` folder with the GPL, LGPL,
Apache-2.0 and MPL-2.0 texts, and each release attaches the corresponding source of the GPL and LGPL
parts. The Rust crates' licences are checked by cargo-deny (`apps/desktop/src-tauri/deny.toml`). This is a
practical summary, not legal advice.
