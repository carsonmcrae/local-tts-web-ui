# Security review for 2.2.0

> **In short:** nothing critical or high is open. The code that landed since the 2.1.0 review keeps to
> the existing boundaries (allow-listed LAN routes, sandboxed parsers, pinned updates, no HTML
> rendering). Four low findings are fixed on this branch (one in the desktop build script), one
> dependency advisory is fixed, and the known residual risks stay as documented, with evidence below.

Reviewed on 2026-10-22 against `consolidate/2.2.0` at e390939 (`main` 5ff1f29 plus one CI commit). The
2.1.0 release-readiness review (2026-10-21) had covered `main` at 177930b in eight areas: speech API
authorisation, LAN pairing and binding, document conversion, voice-pack import, export file names and
filesystem boundaries, temporary files and crash recovery, Audiobookshelf credentials, and upgrades.
Its one functional defect (a global 25 MB body cap) and three hardenings shipped in PR #57. This review
is read-only except for the small fixes named below; it reads code, not docstrings, and cites it. Alongside
it, the threat model gains rows for web-page import, sending to Audiobookshelf and the bundled book catalog,
[supply-chain.md](supply-chain.md) states the real Dependabot cool-downs, and the
[licence inventory](license-inventory.md) lists the bundled books and sound effects.

## Release gate

No critical or high finding is open. R-6 (plain HTTP on the LAN) is the one medium item and is an
accepted, documented, opt-in risk since 2.1.0. R-5 is fixed in the desktop build script, and the
opentelemetry-api advisory (CVE-2026-114603, found by CI's audit) is fixed by 1.45.1. 2.2.0 is not
blocked by anything in this review.

## Not covered

- Fuzzing of the sound-effect lexicon's patterns (reviewed by reading only).
- Running the desktop exit chain or the Job Object on a real machine (code review; the Desktop
  workflow's smoke and update-path tests exercise start and stop).
- cargo-deny on this machine (no Rust toolchain here); the Desktop workflow's result on `main` is cited.
- Whether Playwright 1.64 adds an npm install script (the lock diff shows no change; it is a dev
  dependency and is not installed in release builds).
