# Local TTS

Local TTS reads documents aloud with natural voices, privately, on your own computer. Add a PDF,
Word document, EPUB, Markdown or text file (or paste text), press Play and follow along as each
sentence is highlighted. Optionally, you can create a narration voice from a short recording of
yourself.

Everything runs locally: no accounts, no cloud and no telemetry. The app listens only on
`127.0.0.1` and works offline once its voice model is installed.

## At a glance

|              |                                                                                                                     |
| ------------ | ------------------------------------------------------------------------------------------------------------------- |
| Reader       | PDF, DOCX, EPUB, Markdown, TXT or pasted text; sentence highlighting; chapter and page navigation; resume           |
| Voices       | 54 Kokoro voices in English (US and UK), Spanish, French, Hindi, Italian, Portuguese, Japanese and Mandarin         |
| Voice Studio | Optional Chatterbox Turbo engine; a 10–20 second recording, quality checks, explicit consent and permanent deletion |
| Export       | MP3 or WAV; the whole document, one section or a range; one file or one file per chapter                            |
| Privacy      | Binds to `127.0.0.1`; no telemetry; documents and recordings never leave your computer                              |
| Requirements | Node.js 22.22 or newer and Git; everything else is installed inside the project folder on first run                 |
