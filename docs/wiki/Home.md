# TTSNative

TTSNative reads documents aloud with natural voices, privately, on your own computer. Add a PDF,
Word document, EPUB, Kindle (MOBI), FB2, HTML, Markdown or text file, a web page or pasted text, or
open one of the 25 included public-domain books, press Play and follow along as each sentence is
highlighted. Optionally, you can create a narration voice from your own recordings: a
short clip for a quick voice, or a guided session for a studio voice.

Everything runs locally: no accounts, no cloud and no telemetry. The app listens only on
`127.0.0.1` (and on your home network only while you turn LAN mode on) and works offline once its
voice model is installed. Run it from source today, or, from version 2.1.0 (not published yet), install
the [Windows app](Windows-App).

## At a glance

|              |                                                                                                                     |
| ------------ | ------------------------------------------------------------------------------------------------------------------- |
| Reader       | PDF, DOCX, EPUB, MOBI, FB2, HTML, Markdown, TXT, a web page or pasted text; sentence highlighting; chapters; resume |
| Voices       | 54 Kokoro voices in English (US and UK), Spanish, French, Hindi, Italian, Portuguese, Japanese and Mandarin         |
| Voice Studio | Optional Chatterbox Turbo engine; a quick voice or a guided studio session, quality checks, explicit consent        |
| Export       | MP3, WAV, M4B audiobook or read-along EPUB; the whole document, one section or a range; pause and resume            |
| Privacy      | Binds to `127.0.0.1`; no telemetry; documents and recordings never leave your computer                              |
| Requirements | From source: Node.js 22.22 or newer and Git. Windows app: Windows 11 (64-bit), nothing else                         |
