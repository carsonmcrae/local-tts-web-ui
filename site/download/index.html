What it needs

  • Windows 11 (64-bit) with the WebView2 runtime it includes; the installer fetches WebView2 if it is missing. No administrator rights: it installs for your account.
  • About 1.5 GB of free disk space for the app, its bundled runtime and the default voice. The optional voice-cloning engine adds about 8 GB with an NVIDIA GPU, or 4.5 GB on the CPU.
  • No graphics card needed for reading with the default voices; an NVIDIA GPU speeds up the optional voice-cloning engine.
