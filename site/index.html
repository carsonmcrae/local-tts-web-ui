Free and open source · Runs on your computer

Natural text-to-speech. Private, powerful, and local.

TTSNative reads your PDFs, e-books and documents aloud with natural voices, highlighting each sentence as it speaks. Speech is generated on your own computer: no accounts, no subscriptions, no telemetry and no cloud inference.

Everything you need to listen to a document

  • Any document, read aloud

    PDF, Word (DOCX), EPUB, Markdown, plain text or pasted text. Chapters come from the document's own structure, and you can fix one that starts in the wrong place.

  • Natural voices

    54 Kokoro voices in English (US and UK), Spanish, French, Hindi, Italian, Portuguese, Japanese and Mandarin. Compare them side by side on your own passage.

  • Read along

    The sentence being spoken is highlighted and kept in view. Click any sentence to start there; your place is saved for next time.

  • Starts in about a second

    Sentences are generated just ahead of you and cached, so even a whole book never has to be rendered up front.

  • Study aids

    Search inside a document, bookmarks with notes, a pronunciation dictionary for names, a sleep timer, and adjustable text size and spacing.

  • Audio export

    MP3 or WAV, the whole document or chosen chapters, one file or one per chapter, with optional sentence-timed subtitles.

  • Voice Studio (optional)

    Create a narration voice from your own recording, with explicit consent, live quality checks and noise cleanup. Uses the optional Chatterbox engine.

  • Works offline

    After the first setup downloads the voices, TTSNative needs no internet connection. It listens only on your computer by default.

Try speech in your browser

This demo uses your browser's built-in voices, not TTSNative's. They vary by device and sound different from the Kokoro voices in the app. It reads sentence by sentence and highlights each one, as the app does; the installed app is the real thing.

This voice is an online voice from your browser's maker, so your text may be sent to their servers. Voices without “online” stay on this device.

Private by design

The app runs a small server on your own computer that only listens to your own computer. Your documents, recordings and generated audio stay in its folder. It has no accounts, analytics or telemetry (including ONNX Runtime's, which TTSNative switches off). Besides installing its runtime (uv, Python and locked packages), the only downloads are the voice models, from pinned addresses and checked against fixed SHA-256 checksums.

Voice cloning is optional, needs the speaker's explicit consent, and deleting a voice removes its recordings.

This website

This page has no cookies, analytics or third-party requests: everything is served from this site. The browser demo runs in your browser and nothing you type is sent to us; if you pick an online browser voice, your browser's maker may receive the text, as the demo explains. The site is hosted on GitHub Pages, which, like any web host, logs visitors' IP addresses for security and operations (see GitHub's privacy statement).

Install TTSNative

TTSNative runs from its source code; there's no installer yet. You need Node.js 22.22 or newer and Git. The first run installs everything else inside the project folder. 

git clone https://github.com/carsonmcrae/ttsnative.git
cd ttsnative
npm install
npm run dev
  1. First run sets up Python 3.12 and the locked dependencies (with a checksum-verified copy of uv if you don't have it) and downloads the Kokoro voice model (about 340 MB). Later starts take a few seconds.
  2. Your browser opens at http://127.0.0.1:5173. Drop in a document and press Play. Press Ctrl+C in the terminal to stop.
  3. Voice cloning is optional: install the Chatterbox engine from Settings (about 8 GB with an NVIDIA GPU, about 4.5 GB on CPU).
  4. To uninstall, delete the folder. Nothing is installed system-wide.

How it's built

  • Testing

    Unit and integration tests with 100% line and branch coverage on the server and the web app, and Playwright journeys with real inference across Chromium, Firefox, WebKit and mobile emulation.

  • Security

    Loopback-only by default, CSRF and DNS-rebinding defences, sandboxed document parsing, checksum-verified models, CodeQL, dependency review and signed release provenance.

  • Accessibility

    Targets WCAG 2.2 AA: full keyboard use, visible focus, screen-reader labels, reduced motion and axe checks in the browser tests.

  • Open development

    Source, user guide, architecture and changelog. Designed and built by Carson McRae.

Questions

Is it really free?

Yes. TTSNative is open source under the MIT licence, with no paid tier. The voice models have their own open licences (Kokoro: Apache-2.0; Chatterbox: MIT).

Does it need the internet?

Only for the first setup and to install the optional voice-cloning engine. After that it works offline.

Can I clone anyone's voice?

Only your own, or one whose owner has given you explicit permission (for a child, a parent or guardian). Voice Studio asks you to confirm this before it creates a voice. Everything runs on your computer, so how you use the audio is up to you, and so is the responsibility; see responsible use.

Is the browser demo the same as the app?

No. The demo uses whatever voices your browser provides. The app uses the Kokoro and Chatterbox models on your computer, adds document reading, highlighting, export and Voice Studio.

Can I use it on my phone?

The app runs on a computer. You can then open it from a phone on the same network; see the guide to other devices.

What about scanned PDFs?

Image-only PDFs are detected and reported. Text recognition (OCR) isn't supported yet.

It used to be called Local TTS?

Yes. Version 2.0 was released as Local TTS; the project was renamed TTSNative afterwards. Old links redirect.
