Reader

PDF, EPUB, Word, Markdown and text

Upload a file or paste text. Chapters and pages are found for you, and you pick up where you left off.

Read-along

Fast

Voices

Kokoro voices in nine languages, with quality grades and side-by-side comparison on your own passage.

Optional

Get started

You need Node.js 22.22 or newer and Git. The first run installs everything else inside the project folder: a checksum-verified Python toolchain and the voice model (about 340 MB). No GPU is needed. 

git clone https://github.com/carsonmcrae/local-tts-web-ui.git
cd local-tts-web-ui
npm install
npm run dev

Your browser opens at http://127.0.0.1:5173. The user guide covers installation, voices, voice cloning, exporting and troubleshooting.
